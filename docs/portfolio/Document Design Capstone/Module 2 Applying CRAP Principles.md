# Module 2: Applying CRAP Principles (Contrast, Repetition, Alignment, Proximity)

This analysis evaluates a 2021 California Labor Law Poster used for workplace compliance.

## Design Critique

* **Contrast:** Beyond the initial yellow banner, the document regresses into a dense "wall" of small-print text. The over-reliance on the generic phrase “Employee Rights” fails to distinguish between different legal protections.
* **Repetition:** The poster lacks a unified design system. For example, Federal sections use prominent red headers while California sections use plain black headers, creating a disjointed aesthetic.
* **Alignment:** The document lacks a disciplined grid system, resulting in a "message board" appearance where notices seem taped together haphazardly.
* **Proximity:** Logical grouping is absent. Related topics like "Paid Sick Leave" and "Payday Notices" are separated from the primary "Employee Rights" section, forcing the reader to hunt for information.

## Recommendations

1. **Standardize Headers (Repetition):** Implement uniform font, size, and color for every major law header.
2. **Use Color Coding (Contrast):** Apply distinct color palettes to categorize Federal vs. State mandates.
3. **Enforce a Strict Grid (Alignment):** Rebuild the layout on a formal three-column grid to eliminate the chaotic appearance.
4. **Group by Subject (Proximity):** Consolidate related notices into single visual areas with increased white space.
